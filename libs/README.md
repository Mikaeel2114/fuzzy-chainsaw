# Sidebar libraries (required)

Put these two jars in this `libs/` folder before building:

* `sidebar-base-23.2.jar`
* `sidebar-v1_8_R3-23.2.jar`

They come from the andrei1058 SidebarLib project (https://github.com/andrei1058/SidebarLib).
They are not on any Maven repo this build can reach, so they are loaded from this folder.
